# React useContext Practice Project

A simple React project built to practice the `useContext` hook and understand global state management in React.

## Features

- Theme Switching (Light/Dark Mode)
- User Context Management
- Shared State Across Components
- React Context API
- useContext Hook Practice

---

## Tech Stack

- React
- Vite
- CSS
